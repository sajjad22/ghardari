# گهرداري (Ghardari) 📱🏠

**گهرداري** هڪ مڪمل طور تي آف لائين، نيٽو اينڊرائڊ ايپليڪيشن آهي جيڪا خاص طور تي گهر جي روزمره جي مالي معاملن، مهيني جي مقرر بلن، روزاني خرچن، اڌار کاتي ۽ پوري مهيني جي راشن ۽ سودا سلف جي فهرست سنڀالڻ لاءِ تيار ڪئي وئي آهي.

## سنڌي

### 🌟 مکيه خاصيتون

1. **اڌار کاتو (Udhaar Khata)**:
   - بينڪ اڪائونٽ (منهنجي بئنڪ) ۽ ماڻهن جا کاتا.
   - ڏنا (Debit) ۽ ورتا (Credit) جا سڌا اندراج.
   - 1-ڪلڪ حساب صاف (Clear Account) ۽ واٽس ايپ تي کاتي جي رسيد موڪلڻ.

2. **مهيني جا خرچ (Monthly House Expenditures)**:
   - مهيني ۾ هڪ ڀيرو ادا ٿيندڙ مقرر خرچ (بجلي بل، پاڻي، اسڪول فيسون، اسڪول رڪشا، کير وارو).
   - **ٽو-ڊو لسٽ (TODO List)**: ادا ٿيل (Paid) يا باقي رهيل (Unpaid) چيڪ باڪس.
   - **گذريل مهيني مان نقل (Copy from Previous Month)**: گذريل مهيني جا سمورا بل نئين مهيني ۾ آڻيو، جيڪي پاڻمرادو اڻ ادا (Unpaid) ٿي ويندا ۽ رقم تبديل ڪري سگهجي ٿي.

3. **روزانو خرچ (Daily Expenses Log)**:
   - روزانو ٿيندڙ متفرق خرچن (ماني، سبزي، پاڻي جون بوتلون وغيره) جو ترت اندراج ۽ ڪل حساب.

4. **راشن ۽ سودا سلف لسٽ (Monthly Ration Checklist)**:
   - شين جا نالا، ڪمپني/برانڊ (مثال: شيمپو سن سلڪ، صابڻ لائف بواءِ)، مقدار ۽ ماپ.
   - **دڪاندار لاءِ پرنٽ/PDF لسٽ**: سڌو سنئون PDF پرنٽ يا واٽس ايپ تي موڪلڻ واري فهرست، جنهن ۾ دڪاندار لاءِ رقم لکڻ جي خالي جاءِ موجود هوندي آهي.

5. **مالي رپورٽون (Financial Reports)**:
   - مهيني جو مڪمل مالي تجزيو: ادا ٿيل بل، باقي بل، روزانو خرچ ۽ راشن جو ڪل مجموعو.

6. **تاريخ ۽ آرڪائيو (History & Archive)**:
   - گذريل سڀني مهينن جا محفوظ رڪارڊ ڪنهن به وقت چيڪ ڪريو.

7. **ڊيٽا بيڪ اپ ۽ بحالي (Backup & Restore)**:
   - 1-ڪلڪ JSON بيڪ اپ فائيل ٺاهيو ۽ ان مان سموري ڊيٽا ٻيهر بحال (Restore) ڪريو.

## اردو

### 🌟 نمایاں خصوصیات

1. **ادھار کھاتہ (Udhaar Khata)**:
   - بینک اکاؤنٹ (میری بینک) اور افراد کے کھاتے، ڈیبٹ اور کریڈٹ اندراجات، حساب بےباق اور واٹس ایپ پر شیئرنگ۔
2. **ماہانہ اخراجات (Monthly Expenditures)**:
   - ماہانہ بلز اور فیسیں (بجلی، پانی، اسکول فیس، رکشہ وغیرہ)۔ ٹو-ڈو لسٹ کی طرح ادا شدہ یا غیر ادا شدہ کا نشان۔ پچھلے مہینے سے تمام اخراجات نئے مہینے میں کاپی کرنے کی سہولت۔
3. **روزمرہ اخراجات (Daily Expenses)**:
   - روزانہ کے چھوٹے بڑے اخراجات (کھانا، سبزی، بوتلیں) کا فوری لاگ۔
4. **راشن لسٹ اور دکاندار کے لیے پرنٹ (Monthly Ration)**:
   - اشیاء بمعہ کمپنی/برانڈ نام، مقدار اور اکائی۔ دکاندار کے لیے پرنٹ ایبل PDF لسٹ یا واٹس ایپ میسج۔
5. **مالی رپورٹس اور آرکائیو (Reports & History)**:
   - ماہانہ اخراجات کا جامع تجزیہ اور پچھلے تمام مہینوں کا آرکائیو ریکارڈ۔
6. **بیک اپ اور بحالی (Backup & Restore)**:
   - محفوظ JSON بیک اپ بنائیں اور کسی بھی وقت بیک اپ سے مکمل ڈیٹا بحال کریں۔

## English

### 🌟 Key Features

1. **Udhaar Khata (Lending & Borrowing)**:
   - Default "My Bank" account and personal ledgers. Direct Debit/Credit entries, one-tap account settlement, and WhatsApp statement sharing.
2. **Monthly House Expenditures**:
   - Salaried/Fixed monthly bills (Electricity, Water, School fees, Van/Rickshaw). Interactive Todo checklist (Paid/Unpaid). 1-Click clone from previous month (marked as unpaid fresh for editing).
3. **Daily Expenses Log**:
   - Running log of day-to-day variable expenses (food, vegetables, water bottles, travel).
4. **Monthly Ration & Shopkeeper Printout**:
   - Grocery checklist with item name, company/brand (e.g. Sunsilk, Lifebuoy), quantity, and units. Generates a printable PDF or WhatsApp table formatted with shopkeeper price columns.
5. **Financial Reports & Archive**:
   - Comprehensive breakdown of all household expenses for the active month, plus an Archive section to view historical months.
6. **Backup & Restore**:
   - 1-Click JSON export and 1-Click file restore to safely protect and transfer all records.

## 🛠️ Build & APK

```bash
# Clone the repository
git clone https://github.com/sajjad22/ghardari.git
cd ghardari

# Compile Native Android APK
./gradlew assembleDebug

# Output APK:
# app/build/outputs/apk/debug/app-debug.apk
```

## 📦 How to Publish APK to GitHub Release Assets

To publish the compiled `app-debug.apk` as a downloadable asset on your GitHub repository:

### Method 1: Via GitHub Website (Easiest)
1. Go to your repository on GitHub: **[https://github.com/sajjad22/ghardari](https://github.com/sajjad22/ghardari)**
2. On the right-hand sidebar, click on **Releases** (or click **Create a new release**).
3. Click **Draft a new release**.
4. In **Choose a tag**, type `v1.0.0` and select **Create new tag: v1.0.0 on publish**.
5. Release title: `Ghardari v1.0.0 (گهرداري)`
6. Under **Attach binaries by dropping them here or selecting them**, drag and drop your file:
   ```
   app/build/outputs/apk/debug/app-debug.apk
   ```
   *(You can rename it to `Ghardari-v1.0.0.apk` before uploading)*.
7. Click **Publish release**. The APK will now be permanently downloadable from GitHub Assets!

### Method 2: Via GitHub CLI (`gh`)
```bash
gh release create v1.0.0 app/build/outputs/apk/debug/app-debug.apk \
  --title "Ghardari v1.0.0 (گهرداري)" \
  --notes "First release of Ghardari Household Manager"
```
